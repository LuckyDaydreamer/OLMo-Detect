# OLMo-Detect

This repository contains the benchmark and code for the EMNLP 2026 submission "OLMo-Detect: A Multi-Stage Benchmark for Verbatim Contamination Detection in LLMs".

## Status

- ✅ Benchmark data (contaminated/uncontaminated samples across 9 domains, 4 model sizes)
- 🚧 Detection method implementations (will be added during review period)
- 🚧 Reproduction scripts (will be added during review period)

## Structure

- `benchmark/` — contaminated and uncontaminated samples organized by training stage and domain
- `methods/` — detection method implementations (in progress)
